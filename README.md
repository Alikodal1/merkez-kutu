Merkez Kutu Ambalaj - Web SitesiMerkez Kutu Ambalaj San. Tic. ve Ltd. Şti. için geliştirilmiş kurumsal ve mobil uyumlu web sitesi.

🚀 Özellikler

Mobil Uyumlu (Responsive): Tüm cihazlara tam uyumlu arayüz.

Hızlı İletişim: Doğrudan WhatsApp ve Telefon arama yönlendirmeleri.

Harita Entegrasyonu: Google Haritalar tabanlı konum ve yol tarifi.

Görsel Slider: Üretim parkuru ve makineler için dinamik görsel akışı.

Yüksek Performans: .webp formatında optimize edilmiş hafif görseller.

🛠️ Teknolojiler
HTML5 & CSS3
JavaScript (Vanilla JS)
FontAwesome 6 (İkonlar)
Google Fonts (Poppins)
